# Code of Conduct

## Our pledge

We want PaperTree to be a welcoming project for researchers, students, designers, and developers of all backgrounds and experience levels. Be respectful, assume good intent, and critique ideas rather than people.

This project follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Expected behavior

- Use welcoming and inclusive language.
- Respect differing viewpoints and experiences.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and its users.
- Credit others' work and sources.

## Unacceptable behavior

- Harassment, insults, discrimination, or personal attacks.
- Sexualized language or attention.
- Trolling or deliberately derailing discussions.
- Publishing someone's private information without permission.
- Sharing API keys, private papers, or other confidential material.
- Any conduct that would be inappropriate in a professional setting.

## Scope

This applies in repository issues, pull requests, discussions, and other project spaces, and when representing the project in public.

## Enforcement

Maintainers may remove, edit, or reject comments, commits, code, and other contributions that violate this policy. Repeated or serious violations may result in a temporary or permanent ban from the project spaces.

To report a concern, contact the maintainer privately through the repository profile. Reports will be handled as confidentially as possible.
